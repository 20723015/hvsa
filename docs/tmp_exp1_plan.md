# 研究点一实验方案（HVSA）

## 实验环境

| 项目 | 配置 |
|------|------|
| **硬件** | i7-13700H，RTX 4070，32GB RAM |
| **数据集** | MNIST、CIFAR-10 |
| **模型** | MLP（784-256-10）、CNN（2层 5×5 卷积 + FC 512） |
| **聚合算法** | FedAvg |
| **对比基线** | FedAvg（明文）、VerifyNet、VeriFL、VLMRS、GPVO-FL |
| **层级结构** | 1 Cloud Server + 3 Edge Server + 30 Users |
| **训练参数** | 50 轮通信，5 local epochs，SGD，batch size=64，lr=0.01（MNIST）/ lr=0.001（CIFAR-10） |
| **密码实现** | DH 密钥协商（NIST P-256）、PRF 掩码、LHH（NIST P-256）、ECDSA 签名 |


## 实验主线

实验围绕四个维度评估 HVSA：

1. **训练有效性** — 证明 masking / 分层聚合 / 掉线不影响收敛
2. **隐私保护** — 证明服务器无法从 masked gradient 恢复原始数据
3. **验证正确性** — 形式化验证由 LHH 一致性方程与签名机制保证，实验部分用参数分布一致性图提供可视化支撑
4. **轻量性** — 证明用户端/ES 端/CS 端开销可接受，优于重型方案

# 第二部分：待补充的实验

## N1. Non-IID 数据分布实验

### 目的
验证 HVSA 在 Non-IID 数据分布下与 FedAvg 保持近似的收敛趋势，说明所引入的掩码与验证机制对数据异质性不带来额外显著性能损失。该实验的目标不是证明 HVSA 解决了 Non-IID 问题，而是验证其兼容性与适用性。

### 方法
- 采用 Dirichlet 数据划分，主实验设置 α = 0.5；若时间允许，可补充 α = 1.0 作为较弱异质性对照
- MNIST + CIFAR-10，CNN
- 对比 HVSA vs FedAvg
- 指标：测试准确率 vs 通信轮次、最终测试准确率
- 结论口径：若 HVSA 与 FedAvg 曲线基本贴合，则说明安全聚合与验证机制对 Non-IID 场景具有良好兼容性

### 实验矩阵

| 组别 | 数据集 | 模型 | α 值 |
|------|--------|------|------|
| 1 | MNIST | CNN | 0.5 |
| 2 | MNIST | CNN | 1.0 |
| 3 | CIFAR-10 | CNN | 0.5 |
| 4 | CIFAR-10 | CNN | 1.0 |

### 预期结果
HVSA 准确率轨迹与 FedAvg 基本重合，最终精度差异保持在较小范围内。若出现明显偏差，应进一步区分其来源是 Non-IID 本身导致的收敛波动，还是安全聚合/验证机制引入了额外损失。

### 参考
VPFLI（Fig. 5-8）、G-VCFL（Fig. 5）、VMFL（Fig. 5）

### 产出

**Fig. [non-iid]**: 2×2 = 4 subfigure

| sub | 数据集 | α |
|-----|--------|---|
| (a) | MNIST | 0.5 |
| (b) | MNIST | 1.0 |
| (c) | CIFAR-10 | 0.5 |
| (d) | CIFAR-10 | 1.0 |

每条曲线：HVSA vs FedAvg

正文建议写法：本实验用于验证 HVSA 在数据异质场景下的适用性，而非将 Non-IID 作为单独优化目标。

**sub 计数：4**


## N2. DLG 攻击防御实验

### 目的
用实验证明 HVSA 的 PRF masking 能防御梯度泄露。安全分析声称 CS 无法从 masked gradient 恢复原始数据，需实验支撑。

### 方法
- 攻击算法：DLG（Zhu et al., NeurIPS 2019）
- MNIST + CIFAR-10
- 对比设置：

| 设置 | 配置 | 预期结果 |
|------|------|---------|
| 无保护 FL | 明文梯度 | 能清晰恢复原始图像 |
| **HVSA** | PRF 掩码后的梯度 | 只能看到随机噪声 |

- 指标：重建图像与原始图像的 PSNR / SSIM

### 预期结果
无保护下 PSNR > 20（可辨识），HVSA 下 PSNR < 10（纯噪声）。

### 参考
SAEV-FL（Fig. 8）、GPVO-FL（Fig. 8）

### 产出

**Fig. [dlg]**: 6 subfigure（参考 SAEV-FL Fig.8 布局）

| sub | 数据集 | 内容 |
|-----|--------|------|
| (a) | MNIST | 原始训练图像 |
| (b) | MNIST | 无保护 FL → DLG 恢复 |
| (c) | MNIST | HVSA → DLG 恢复（噪声） |
| (d) | CIFAR-10 | 原始训练图像 |
| (e) | CIFAR-10 | 无保护 FL → DLG 恢复 |

## N7. 聚合模型参数分布一致性展示

### 目的
参考 VLMRS Fig. 6，在验证通过时从统计角度展示聚合模型参数分布与本地模型参数分布保持一致，为验证机制提供可视化辅助证据。

**注意**：这是直观展示实验，不是密码学验证证明；形式化验证依据是 LHH 一致性方程 + 签名验证。

### 参考：VLMRS Fig. 6 设计

VLMRS（Li et al., IEEE TDSC 2026）展示了：
- (a) epoch=35，4 个 client 本地参数分布
- (b) epoch=79，4 个 client 本地参数分布
- (c) epoch=35，聚合模型参数分布
- (d) epoch=79，聚合模型参数分布

各层参数服从正态分布，聚合后分布与本地分布一致。

### HVSA 具体做法
- 随机选 4 个用户，记录 epoch 早期（epoch=20）和晚期（epoch=50）的本地模型参数和聚合模型参数
- 绘制 4 层参数（input.weight, input.bias, hidden.weight, hidden.bias）的分布直方图
- 4 用户本地分布用不同颜色叠加，聚合模型分布单独展示

### 产出

**Fig. [dist]**: 2×2 = 4 subfigure

| sub | epoch | 内容 |
|-----|-------|------|
| (a) | 20 | 4 用户本地参数分布 |
| (b) | 50 | 4 用户本地参数分布 |
| (c) | 20 | 聚合模型参数分布 |
| (d) | 50 | 聚合模型参数分布 |
