# 研究点一实验小节初稿（2026-10-23）

本稿整理截至本日已经完成的实验，供毕业论文实验部分选用。章节和图表编号可按论文调整。三方案成本属于明确实例化比较；待补任务在文末列出，不把计划写成结果。已录用论文与答辩PPT未在本轮修改。

## 1. 实验设置与计量方法

HVSA采用单个完全可信且不合谋的TA、多个边缘服务器、多个客户端及不可信云服务器。客户端使用与TA协商的种子生成单路掩码；边缘生成签名证据并核验云返回的原始整数和，验证后确定性重构模型。隐私边界针对实际释放聚合中的客户端人数N：在至多N−2个客户端合谋时，仍需至少两个非合谋客户端。组/全局聚合及总掩码允许公开；最小接纳人数不等同合谋阈值。通信遵循项目既定理想安全信道假设。

跨方案成本实验选取N∈{20,50}、模型维度D∈{1000,7850}，分层方案边缘数M=5；VLMRS为平面方案，不设边缘层。每个方案在每个工作点执行3次预热和10次正式观测，共156次完整聚合，其中120次用于成本统计。同一工作点的三方案使用相同归档整数输入和实际参与集合，每轮轮换执行顺序；量化不重复计入协议时间。初始化成本单列，逐轮必要密钥分发、证明、恢复及验证均计入对应角色。

GPVO实例化固定为模N_RSA²的乘法LHF、3072位RSA模数、大于N_RSA²的素数指数以及逐轮新DH会话。这里N_RSA表示RSA模数，与客户端人数N区分。随机单位元生成元未给出最大阶证书，该整数群接口不声明等同原文实验的P-256接口。VLMRS采用全邻居图、ceil(2N/3)恢复阈值、公开根指数7、共享秘密线性HF与两组长期DH密钥复用。上述选择由本项目明确固定，并保留相应异常行为诊断；它们不是作者代码或安全等价认证。

客户端计算指标为每轮全部客户端互斥工作之和除以所选人数N，再取10轮中位数。系统计算指标为每轮所有角色互斥工作的总和。通信指标为实际逐接收者协议封装字节，不包含TCP/TLS头和估计RTT。计算图使用对数纵轴，误差线为四分位区间。所有协议均在本机串行回放，因此系统工作与回放耗时不解释为真实多机部署时延。

具体平台、Python/密码库版本、公开参数、源码与输入摘要在各运行manifest中保留。GPVO使用gmpy2原生模幂，VLMRS配对使用py-ecc 8.0.0；HVSA与GPVO生成元缓存容量分别为4096与131072。不同后端、缓存及可信设施的影响必须与协议结构差异共同解释。N20点采于10月19日、N50点采于10月20日，不将跨时段变化全部归因于人数。

## 2. 聚合正确性与篡改检查

HVSA自身E1覆盖100组小维度独立输入以及10份不同真实训练快照，110/110次去掩码后的原始整数和均逐维等于同编码明文参考，完整验证通过。当前E5覆盖18类用例、每类100组小维度输入和10份完整维度快照，1980次篡改全部被拒绝；330次对应诚实上下文均正确。签名绑定轮次、基模型和在线摘要，证据集合及输出域检查属于当前实现路径。此前发现并修复的两处漏检属于实现修复，不作为额外密码学创新。

三方案明确实例化的小维度试跑包含诚实输入、上传前20%离线与上传后20%离线，共9/9次正确且验证通过。上传前离线发生在本轮必要初始化或份额分发之后、模型上传之前。四点成本矩阵另有156/156次诚实聚合正确且完整验证通过。试跑、成本观测和HVSA独立E1/E5各有不同用途，不合并为单一成功率。诚实结果正确也不代替恶意条件下的完整性证明。

协调修改及原样重放的错误接受按固定实现条件保留，不直接判为原论文漏洞。110份当前输入独立，但每个维度复用固定重放锚点与方案规定的长期密钥，不解释成110套独立密钥。零扩维定位为本项目GPVO适配器缺少显式长度检查，VLMRS入口拒绝；此项不作为HVSA密码学贡献或协议安全排名依据。

VLMRS还在3个维度分别记录后续恢复长期掩码私钥后重构过去上传的诊断，其中3/3次逐维恢复。该结果限定于本项目长期密钥复用、后续允许恢复该私钥的生命周期选择。原样重放不包含利用当前证明重新协调构造旧值，不能把原样重放拒绝扩大为所有旧值替换均被阻断。

本轮诚实协议的全部指定验证者均执行，但篡改调用一个代表验证者，不是恶意云向全体验证者广播的端到端攻击实验。输入拒绝、验证返回False与接受结果分别保存，不以汇总拒绝率排列协议安全性。详见[六类异常结果](POINT1_DECLARED_INTEGRITY_RESULTS_20261023.md)。

## 4. HVSA规模、多轮与掉线实验

HVSA自身规模实验覆盖N=20/50/100/200、D=1000/7850/10000/30000/100000及M=2/5/10，重合点去重后共10个工作点，130轮全部正确且验证通过，其中100次为正式观测。该矩阵与本节三方案比较分开归档；部分较早N扫描的源码版本不同，不能直接拼成同一冻结版本的跨方案曲线。

多轮实验分别执行固定50人上传与从50名注册者中每轮变化在线集合、保持40人上传两条轨迹，各50轮，100/100次正确且验证通过，初始化只执行一次。这支持当前实现的跨轮执行与记录，但两条轨迹每轮上传人数不同，尚不能把耗时差解释为参与变化或密钥复用收益；相同人数的对照轨迹仍需补充。

随机掉线覆盖上传前/上传后、0/10/20/30%四种比例及10个种子，共80次聚合，全部正确且验证通过。另设N=100、M=5、D=7850的定向边界：同一组20人在上传前全部缺席时，点一停在4/5组同步屏障；该20人上传后离线及全体客户端上传后离线时，已上传贡献均正确聚合、验证通过，模型分别向80人和0人下发。三例边界中只有两例完成聚合，不将同步屏障失败计作篡改拒绝，也不由随机30%成功推出任意集中30%均可完成。

## 5. 消融与训练衔接

HVSA消融设置两个维度和四种控制：单掩码、额外两路可抵消掩码、仅边缘验证关闭、完整验证关闭。共104轮原始整数和正确，52次启用验证的回合全部通过，52次关闭组的verified记为空值。额外掩码控制用于隔离掩码计算作用，不等同GPVO协议。

真实训练采用MNIST、784→10线性模型，D=7850、20个客户端及5个边缘，3个种子各20轮。60/60次聚合正确且验证通过，末轮准确率均值86.803%，样本标准差0.107个百分点。浮点参考仅对同一批本地更新作平均，未另行运行独立FedAvg训练轨迹，因此该结果支持聚合与训练衔接，不支持精度领先结论。

## 6. 结论范围与待补实验

已完成结果支持：在单可信TA和既定编码下，HVSA所测完整链路能够正确聚合，边缘完成验证，客户端工作较轻；在本项目明确实例化的四点成本比较中，客户端与全体角色计算低于GPVO实现，但通信存在配置相关的取舍。结论限定于记录的实现、参数、可信设施与后端。

GPVO协调修改结果/承诺及VLMRS公开根指数缩放、后续长期私钥恢复的既有条件诊断继续保留，不能因诚实回合通过而改写成安全等价；也不能把该选择下的现象直接判为原论文漏洞。10月20日成本阶段没有新增异常矩阵；本次已补固定实例化的六类验证行为，跨方案同人数多轮与完整分阶段掉线仍待补。这些结果与更广的原文等价证明、全部规模扫描及SOTA判断相区分。

待补顺序为：固定相同上传人数的多轮轨迹；三方案分阶段掉线；根据实测可行性选择新增规模点。新增结果使用独立版本和归档，不覆盖已有观测。
