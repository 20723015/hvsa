# 三方案N100分阶段掉线：运行前规格

日期：2026-10-24。用户授权继续，承接已完成的N50同人数50轮实验和论文稿v5。冻结协议、实例化选择、库与缓存；不操作电源，不重写历史结果。

## 固定设计

- 注册100人，分层方案5组，维度7850，种子42；分组使用原partition_users、最小组大小2。VLMRS为平面全邻居图，固定恢复阈值ceil(200/3)=67。
- 上传前/上传后掉线各0%、10%、20%、30%，8个格子各10条共同输入/名单，三方案共240次真实调用。每格每方案单独初始化一次，共24个连续状态；在同一进程内保留到结束，不合并此前8+2分段状态。
- 第i条全注册者整数向量池由种子400042+i生成，int64、各维范围[-10^9,10^9)。每条池供8个格子及三方案共用；这是协议回放，HVSA使用默认零基模型，不是SGD训练/收敛实验。
- 第i条共同排列由种子40042+i生成，取前N×比例为掉线者；四档名单嵌套，两个掉线阶段共用同一名单，不按方案重采样。10条指输入/排列种子独立，不表示每格10套独立密钥或机器重复。
- 上传前：名单/必要分享已分发后退出，缺席者不上传，剩100/90/80/70人贡献并接收模型。上传后：全部100人已上传，缺席者不再参与恢复/接收，剩100/90/80/70人；参考和仍包含全部100人。边缘与TA在线。
- 每个状态连续执行i=0…9；各i反转格子先后、循环轮换三方案次序。先初始化全部24个状态；GPVO各格独立公参、逐轮新DH及承诺随机量，初始化成本单列。VLMRS长期密钥复用和已披露历史条件保持，不私自刷新修补。

## 计量与判定

所有指定边缘/恢复客户端执行完整验证，不抽取代表验证者。逐调用记录共同输入、实际上传/恢复/接收者、原始返回整数和、全部验证判定、阶段/角色互斥耗时、真实逐接收者封装字节。GPVO邻居补偿消息数量另按真实环邻接边界核对；VLMRS记录恢复出的缺席掩码私钥名单，上传后退出不能删掉其已上传贡献。

独立核验整数和、完整验证及实际接收者；先按固定名单推导可用性，出现空组/恢复不足也保留成本和失败原因，不重采样，不把未完成计作篡改拒绝。性能汇总显示所有原始点、完成/未完成计数、初始化及逐角色成本，不删除首轮或异常耗时，不用单轮乘10。

每次初始化/调用前后只读保存供电、报告CPU频率、系统/进程CPU计数、内存及其他协议worker观察。仅一个密码计算worker，不修改频率/温度/优先级/电源设置。连续单初始化和快照观察可弥补状态分段问题，但不等于硬件条件完全锁定。局部串行角色工作不解释为真实多机网络时延；基线明确实例化、信任/后端/缓存/安全差异继续披露，不据此宣称SOTA。

## 归档与顺序

先以N10/M2/d4、前/后各0%和30%、各1条共12次做独立试跑，保留同样生产密码参数。检查名单阶段语义、分片不可覆盖、改写后仍不能伪造实际和/验证者/接收者/状态及覆盖范围；试跑不计入正式数据。

正式返回后使用不可覆盖分片和原子journal逐次登记；10个共同输入NPZ共享，完成后流式合并。单次初始化/调用1800秒期限；异常或用户暂停时保留登记前缀和在途上下文，未返回调用不能冒充完整成本。进程丢失后不声称恢复原私钥状态。
