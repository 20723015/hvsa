# 三方案大规模同人数多轮：运行前规格

日期：2026-10-24。用户授权继续。承接论文稿v4及定向掉线边界，推进原计划E3的N50/M5/d7850工作点。不重写既有实验，不修改冻结协议/参数选择/库/缓存，不操作电源。

## 固定工作点与顺序

- 注册50人、分层方案5组、维度7850、种子42；VLMRS为平面全邻居图，恢复阈值ceil(100/3)=34。两条轨迹每轮都上传40人：一条固定名单，另一条逐轮变化名单。离线发生在名单/必要分享分发后、模型上传前；边缘与TA在线。
- 固定名单为变化轨迹第0轮名单。按种子10042+i生成全注册者排列并取前10人为缺席，固定轨迹始终使用i=0。分组按原partition_users的种子42构造，不为了成功重新采样名单。
- 第i轮使用种子100042+i生成一份全注册者整数向量池，正/负值幅度小于10^9；两轨迹及三方案共享该池。参考和分别按两轨迹实际上传者计算，除第0轮外不要求两轨迹输出相同。它是合成输入协议轨迹，不是训练收敛曲线。
- 两轨迹各50轮、三方案共300次实际完整协议调用。奇数轮反转轨迹先后，每个轨迹/轮的三方案顺序循环轮换。每个方案每条轨迹只初始化一次，共6个状态；GPVO逐轮新DH/承诺随机量，VLMRS长期密钥复用和已记录条件行为保持。
- 两个GPVO状态独立生成公开参数，初始化差异单列，不把随机公参耗时差异全部解释为成员变化。累计/摊销取实际前缀1/10/50，不用单轮乘轮数；不丢弃首轮，无预热排除。

规格制定时的一次只读观察为接通电源、电池77%、报告CPU频率3601MHz；正式执行以实际快照为准。每次初始化/聚合前后保存供电、频率、系统CPU计数及进程内存等只读快照；不改变电源方案、频率、优先级或缓存容量。只运行一个密码计算worker。

同一进程、源码/库与连续状态减少重启/跨日混合，但不是温度和频率锁定的实验平台。若供电/并发条件变化，原始记录保留并在报告中明确标记；不能仅凭接通电源宣称完全同条件。此前8+2分段E4和N100掉线矩阵不因此自动补齐。

初始化、各角色互斥工作、真实逐接收者封装字节分别计量。环境采集、输入生成/归档、参考计算、落盘及绘图在协议计时之外。串行回放不解释为真实多机网络时延；后端、信任设施、安全性质和缓存差异继续单列，不作为安全等价或SOTA排名。

## 归档与异常规则

每次返回后将阶段、消息、实际返回和、逐验证者判定、上传/模型接收名单及环境快照写成一个不可覆盖的分片，完成后原子登记到journal；进度文件仅保存登记前缀。输入NPZ按轮共享。最终流式合并原始阶段/消息，不把大量记录反复写入单个检查点。

独立核验每个分片的摘要/归属、共同输入、实际整数和、所有5个边缘或40个恢复客户端的验证调用与实际接收者，逐项核对角色/通信及累计统计；首次正式轮也按同一规则核验。记录GPVO每轮公开会话指纹，检查不重复。

空组、恢复不足、错误和/验证失败均如实归档，不作有利重采样。异常/1800秒单次期限保留已登记完整前缀和当前调用信息；没有返回的在途工作不能冒充完整成本。进程丢失后私钥状态不可直接恢复，不提供伪装同一状态的自动续跑。用户明确暂停时停止并保存；后续若接续，另建状态与来源说明。
