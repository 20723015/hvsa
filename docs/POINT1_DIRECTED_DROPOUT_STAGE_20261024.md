# 三方案定向掉线边界：执行规格（2026-10-24）

本规格在运行前固定。承接三方案300项分段补充，补查集中掉线、环邻居位置和恢复阈值；不重复成本矩阵，不修改冻结协议，不操作电源。

## 工作点与输入

- 注册20人、分层方案5组，每组4人，组内按u0…u19的数值顺序构成环；VLMRS仍为平面全邻居图、恢复阈值14。维度257，整数幅度小于10^9，种子42。
- 每个情形3份独立向量池，12个情形共享同一重复编号的池，三方案共享同一输入/上传/恢复名单；共同输入池仅3份，不声称36份独立样本。每次协议调用使用唯一轮次，方案次序轮换，偶数/奇数重复反转情形顺序。
- 每方案只初始化一次，按既定生命周期跨情形复用；GPVO每轮仍重新分发DH会话。不同重复不代表独立长期密钥。完整指定验证者均实际执行。
- 上传前缺席发生在本轮名单/必要分享完成后、模型上传之前；不测试注册/份额分发期间离线。上传后缺席保留已上传贡献，只减少恢复者及接收者。边缘与TA始终在线。

## 证据与核验

沿用10月20日成本阶段冻结的关键源码及10月19日实例化决策。独立归档源码、规格、初始参数、初始化计量、共同输入NPZ、实际返回和NPY、原始阶段/消息、逐验证者判定及失败原因；每次返回后保存完整前缀。超时/异常保存现有记录，不自动重启、不重采样。
