## 阅读顺序

1. 先确认两个研究点各自要解决的问题与当前完成阶段。
2. 查看公共角色与协议链路；点一从`HVSAProtocol`读起，点二从`run_point2_simulation`读起。
3. 按实验分类查入口、配置和测试。运行命令必须从仓库根目录执行。
4. 读实例化决策与实验口径后再解释结果。验证关闭组、预热、失败、未完成前缀与正式完整观测分别统计。

本目录是2026-10-28整理并整合到`main`的代码审阅入口。师姐可用[文件清单](catalog.json)定位代码；本地运行状态仍以主实验线程的实时记录为准。
